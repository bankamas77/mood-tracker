# mood-tracker

Трекер настрою та емоцій — навчальний проєкт курсу «Програмування веб-застосувань» (2 курс, ФІОТ КПІ), варіант №3.

- Практикум 1: базовий HTML5-каркас.
- Практикум 2: семантична розмітка HTML5.
- Практикум 3: базові стилі CSS, box model.
- Практикум 4: адаптивна верстка (Flexbox, Grid, медіа-запити).
- Практикум 5: візуальний дизайн (кольори, типографіка), див. DESIGN.md.
- Практикум 6: основи JavaScript (script.js).

Практикум 7: маніпуляція DOM за допомогою JavaScript (querySelector, createElement, textContent, classList, dataset).
Практикум 8: обробка подій та форми, клієнтська валідація (addEventListener, preventDefault, setCustomValidity, form.reset).
Практикум 9: клієнт для API (fetch, async/await, обробка помилок, стан завантаження).
Практикум 10: Vue 3 через CDN, компонент MoodEntry (props, v-for, computed).
Практикум 11 (частина 1): localStorage — збереження записів між перезавантаженнями сторінки.
